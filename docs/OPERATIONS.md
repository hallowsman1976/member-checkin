## ขั้นตอนที่จุดลงทะเบียน (staff)

1. พิมพ์เลขสมาชิกหรือชื่อ → ↑↓ เลือก → **Enter**
2. ตรวจบัตรประชาชน/บัตรสมาชิกให้ชื่อตรงกับหน้าจอ → **Space** ติ๊ก "ตรวจบัตรแล้ว" → **Enter** ยืนยัน
3. เห็น "ลงทะเบียนสำเร็จ" → ช่องค้นหาพร้อมสำหรับคนถัดไป
- ถ้าขึ้น **"สมาชิกลงทะเบียนไปแล้ว"** แจ้งเวลาและจุดที่ลงไว้ — ห้ามลงซ้ำ ส่งต่อหัวหน้างานถ้าสมาชิกยืนยันว่ายังไม่เคยลง
- ถ้าขึ้น **"ไม่ทราบผล (การเชื่อมต่อขัดข้อง)"** ห้ามกดซ้ำ รอเน็ตกลับแล้วกด **"ตรวจสอบสถานะอีกครั้ง"** ระบบจะบอกว่าบันทึกแล้วหรือยัง

## ขั้นตอนกระดาษสำรอง (Offline fallback)

ระบบ **ไม่มีโหมดออฟไลน์** โดยตั้งใจ เพื่อไม่ให้เกิดการลงทะเบียนซ้ำข้ามเครื่องที่ตรวจสอบไม่ได้

1. หัวหน้างานประกาศ "เปลี่ยนเป็นกระดาษ" ทุกจุดหยุดใช้ระบบพร้อมกัน และจดเวลาที่เริ่ม
2. แต่ละจุดค้นชื่อในรายชื่อที่พิมพ์ไว้ ตรวจบัตร แล้วเขียนลงแบบฟอร์มกระดาษ (เวลา, เลขสมาชิก, ชื่อ, ✓ ตรวจบัตร, ลายเซ็น)
   - ขีดฆ่าชื่อในรายชื่อที่พิมพ์เพื่อกันซ้ำภายในจุด ถ้าสมาชิกบอกว่าลงที่จุดอื่นแล้ว ให้ถามจุดนั้นก่อน
3. เมื่อระบบกลับมา: หัวหน้างานประกาศกลับไปใช้ระบบ — **คิวใหม่ใช้ระบบก่อน** แบบฟอร์มกระดาษเก็บรวมไว้ที่ admin
4. admin (หรือเจ้าหน้าที่ที่ได้รับมอบหมาย) คีย์ทุกรายการจากกระดาษผ่านหน้า **ลงทะเบียน** ตามปกติ
   - ถ้าระบบแจ้ง "ลงทะเบียนไปแล้ว" = ซ้ำกับที่ลงในระบบก่อน/หลังล่ม → ไม่ต้องทำอะไร แต่ทำเครื่องหมายในกระดาษ
   - เวลาลงทะเบียนในระบบจะเป็น **เวลาที่คีย์** ไม่ใช่เวลาจริง — เก็บแบบฟอร์มกระดาษไว้เป็นหลักฐานเวลาจริง
5. ตรวจยอด: จำนวนในแดชบอร์ด = ยอดก่อนล่ม + รายการกระดาษที่ไม่ซ้ำ
